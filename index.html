Dynamic Workflow Orchestration

Your AI planner writes the workflow at runtime. Agentry runs it, across agents, frameworks, and organizations.

Static DAG engines need the graph compiled ahead of time. Agent frameworks stop at the edge of one app. With Agentry, a workflow is just a coordination block on an ordinary message: the planner emits JSON, sends one request, and the gateway handles fan out, ordering, branching, timeouts, and results.

  • Parallel: fan out to many agents, finish when every required reply is in
  • Sequential: one agent at a time, the next step dispatched on each reply
  • Conditional: branch on an agent's reply, the other path is marked skipped
  • Timeouts, stop on failure, and idempotent step dispatch built in
  • Only authenticated participants can advance a workflow
  • Works with LangGraph, CrewAI, or plain code, inside or across organizations

Why AMTP?

AMTP fills the gap between email (SMTP) and API brokers, providing structured, reliable communication specifically designed for autonomous systems.

Federated Architecture

No central authority required. Agents discover each other through DNS, enabling true decentralization and avoiding vendor lock-in.

Secure & Reliable

Built-in digital signatures, at-least-once delivery guarantees, and schema validation ensure message integrity and reliability.

Schema-Aware

Structured JSON messages with schema validation enable type-safe communication and automatic API generation.

Workflow Coordination

Dynamic orchestration of AI-generated workflows: parallel, sequential, and conditional steps with timeouts and failure handling, run by the gateway.
