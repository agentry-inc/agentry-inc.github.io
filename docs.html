Quick Start

Get up and running with AMTP in minutes.

Deploy Agentry Gateway with Docker

# Build the image
git clone https://github.com/amtp-protocol/agentry.git && cd agentry
make docker-build

# Create an admin key and run the gateway
mkdir -p keys && openssl rand -hex 32 > keys/admin.keys
docker run -d --name agentry -p 8443:8443 \
  -e AMTP_DOMAIN=yourcompany.com \
  -e AMTP_TLS_ENABLED=false \
  -e AMTP_ADMIN_KEY_FILE=/app/keys/admin.keys \
  -v $(pwd)/keys:/app/keys:ro \
  agentry:latest

# Check status
curl http://localhost:8443/health

# Register a pull-mode agent (the response contains its api_key)
curl -X POST http://localhost:8443/v1/admin/agents \
  -H "Content-Type: application/json" \
  -H "X-Admin-Key: $(cat keys/admin.keys)" \
  -d '{"address": "assistant", "delivery_mode": "pull"}'

# Read its inbox
curl -H "Authorization: Bearer <api_key>" \
  http://localhost:8443/v1/inbox/assistant@yourcompany.com

AMTP Protocol Specification

The complete specification for the Agent Message Transfer Protocol v1.0.

Message Format

AMTP messages are structured JSON documents that contain all necessary information for routing, delivery, and processing by autonomous systems. 

POST /v1/messages
Authorization: Bearer <sender agent api_key>

{
  "sender": "orders@company.com",
  "recipients": ["fulfillment@partner.com"],
  "subject": "New order",
  "schema": "agntcy:commerce.order.v1",
  "headers": { "priority": "high" },
  "payload": {
    "action": "process_order",
    "data": { "order_id": "ORD-001", "amount": 99.99, "currency": "USD" }
  }
}

Required Fields

  • sender - Sender address in the form agent@domain
  • recipients - One or more recipient addresses in the form agent@domain

Optional Fields

  • subject - Short human-readable summary
  • schema - AGNTCY schema ID (agntcy:domain.entity.version) used to validate the payload
  • payload - The message content, any JSON value
  • headers - Additional key-value metadata
  • attachments - File references with filename, content type, size, hash, and URL
  • coordination - Turns the message into a workflow: parallel, sequential, or conditional
  • workflow_id, response_type - Used by agents replying to a workflow step
  • in_reply_to - The message_id being answered

Set by the Gateway

  • version, message_id (UUIDv7), idempotency_key, timestamp - Generated when the sender omits them
  • signature - Domain signature over the RFC 8785 canonical JSON body (ES256 or RS256), verified against the sender domain's DNS key

Gateway Setup Guide

Deploy and configure Agentry Gateway for your environment.

Docker Compose with PostgreSQL

For production, store messages and workflow state in PostgreSQL so multiple gateway replicas can share it. Run this from the root of the agentry repository: the schema in deployment/db is loaded when the database starts. 

# docker-compose.yml
services:
  agentry:
    image: agentry:latest   # built with make docker-build
    ports:
      - "8443:8443"
    environment:
      - AMTP_DOMAIN=yourcompany.com
      - AMTP_TLS_ENABLED=true
      - AMTP_TLS_CERT_FILE=/app/certs/tls.crt
      - AMTP_TLS_KEY_FILE=/app/certs/tls.key
      - AMTP_ADMIN_KEY_FILE=/app/keys/admin.keys
      - AMTP_STORAGE_TYPE=database
      - AMTP_STORAGE_DATABASE_DRIVER=pgx
      - AMTP_STORAGE_DATABASE_CONNECTION_STRING=host=postgres port=5432 user=agentry password=change-me dbname=agentry
      - AMTP_LOG_LEVEL=info
    volumes:
      - ./certs:/app/certs:ro
      - ./keys:/app/keys:ro
    depends_on:
      postgres:
        condition: service_healthy
    restart: unless-stopped

  postgres:
    image: postgres:16
    environment:
      POSTGRES_USER: agentry
      POSTGRES_PASSWORD: change-me
      POSTGRES_DB: agentry
    volumes:
      - ./deployment/db:/docker-entrypoint-initdb.d:ro
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U agentry"]
      interval: 10s
      retries: 5

volumes:
  postgres_data:

On Kubernetes, use the Helm chart in deployment/chart. To make your domain reachable, publish _amtp.yourcompany.com. IN TXT "v=amtp1;gateway=https://amtp.yourcompany.com:443".
